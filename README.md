# JPMorgan Chase & Co. – Advanced Software Engineering Virtual Experience

This repository contains my completed work for the JPMorgan Chase & Co. Advanced Software Engineering Virtual Experience Program on Forage.

## Overview

The project focuses on building and extending a Spring Boot application that simulates core banking operations.

Key areas covered include:

- Java Development
- Spring Boot
- REST API Design
- Event-Driven Architecture
- Kafka Messaging
- Database Integration
- Unit Testing
- Software Engineering Best Practices

## Tasks Completed

### Task 1 – Environment Setup
- Configured development environment
- Built and executed the application

### Task 2 – Data Model Implementation
- Implemented core data entities
- Connected application components

### Task 3 – Transaction Processing
- Processed financial transactions
- Updated account balances

### Task 4 – Event Streaming
- Integrated Kafka event handling
- Processed transaction events

### Task 5 – REST API Controller
- Implemented REST endpoints
- Exposed balance information through API
- Added controller logic and integration testing

## Running the Project

Clone the repository:

```bash
git clone https://github.com/saugatp0kharel/forage-midas.git
```

Run tests:

```bash
mvn clean test
```

Run the application:

```bash
mvn spring-boot:run
```
